# v0.1.5

Native Codex Computer Use repair update for macOS installations where the
official Computer Use tools are missing, hidden, timing out, or not yet working
after Codex was installed.

## What Changed

| Area | Change |
| --- | --- |
| Native smoke | Fresh smoke now records the current boot/runtime context and fails closed when the Mac boot session, Codex executable, bundled Computer Use version, native binary, or guard binary changes. |
| Status safety | `codex-computer-use-guard status` remains read-only and no longer kills orphan native MCP processes or rewrites the latest status snapshot. |
| Duplicate MCP cleanup | Full `ensure` still repairs duplicate native MCP ownership by keeping the newest native client per Codex AppServer parent and removing older duplicate transports before reporting operational health. |
| Codex app path | Persisted and environment-provided Codex app paths must be absolute `.app` paths and are verified as the OpenAI Codex bundle before persistence or native smoke execution. |
| Rollback | Snapshot rollback refuses symlink targets that would restore links outside the selected home directory. |
| Installer | Snapshot directories are collision-resistant when multiple installs happen in the same second. |
| Verifier | Live verification now checks the persisted Codex app bundle id, LaunchAgent app-path consistency, full native smoke fields, Safari click/type evidence, cleanup evidence, and smoke context freshness. |
| Public safety | The public audit now fails on local Finder metadata and Python bytecode caches in the public workspace. |
| Docs | README and install docs are simpler, text-only, SEO-oriented, and focused on using Computer Use repair rather than maintainer release work. |

## Security Boundary

This release repairs and validates the official native OpenAI Codex Computer
Use path. It does not bypass OpenAI usage policies, OpenAI safety checks, macOS
privacy controls, account protections, or third-party security controls. It
does not hide AppleScript, Accessibility scripting, screenshots, Playwright,
Keyboard Maestro, Haindy, VPN, or `cliclick` inside the native Computer Use MCP
path.
