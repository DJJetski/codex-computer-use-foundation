# v0.1.11

Fresh-thread proof and capability-parity hardening after v0.1.10.

## What Changed

| Area | Change |
| --- | --- |
| Current-thread transport | Clarified and encoded that `native_computer_use_ready` proves the installed route, but an already-open thread still needs a successful `mcp__computer_use__.list_apps` call. If it returns `Transport closed`, use a fresh Codex thread after repair. |
| Official capability parity | Expanded the parity document to reflect OpenAI's app-level wording for screenshots, windows, menus, keyboard input, and clipboard state, while keeping the exact current Codex app MCP tool list unchanged. |
| Native smoke robustness | Moved the authoritative smoke to Calculator, clicks by `get_app_state` element index, attempts to return focus to Codex first, and records `coordinate_click_attempts` plus target frontmost state as health evidence. |
| Guard status | Updated the ready-state `next_step` so it no longer says an arbitrary current thread can continue without a live native probe. |
| Public docs and audits | Added release-surface checks for the current-thread transport and clipboard-state language so future releases keep this distinction visible. |

## Why

The native route can be fully repaired while a thread that loaded MCP metadata
before repair still has a closed transport. That does not mean the installed
Computer Use route lacks parity; it means the current thread is stale. The
correct post-repair proof is a fresh Codex thread, `tool_search` if needed, and
`mcp__computer_use__.list_apps` before continuing.

This release makes that behavior explicit without adding fake MCP tools or
falling back to AppleScript, screenshots, `cliclick`, Playwright, or Keyboard
Maestro.

The smoke still preserves coordinate clicks as part of the native Computer Use
tool surface; it simply requires semantic element-index clicks for operational
health so the release proof is deterministic. Calculator is used because it is
a low-risk native app-state surface and avoids overclaiming browser DOM
accessibility that the current bundled plugin does not consistently expose.
