# v0.1.14

Chrome Browser Use force-repair and fresh native Computer Use proof release.

## What Changed

| Area | Change |
| --- | --- |
| Native Computer Use | Reverified the installed route with a fresh full `ensure`: all health layers are true, smoke is fresh, and `fallback_used=false`. |
| Chrome Extension force repair | The guard now treats native-host, Chrome force-install policy, external-extension file, browser-client, and local Chrome skill materialization as repairable local state once the bundled Chrome plugin cache is healthy. |
| Chrome skill guidance | The installed Chrome skill copy is patched so agents force-repair through the Foundation guard before telling the user to reinstall manually. |
| Browser Use backend selection | Chrome Browser Use guidance now selects the `type="extension"` backend by the id returned from `agent.browsers.list()`, instead of assuming the literal id `"extension"` works in every runtime. |
| Public docs | README, runbook, architecture, current-state, install, and parity docs now describe Computer Use, in-app Browser Use, Chrome target smoke, and Chrome Extension Browser Use as separate validated routes. |
