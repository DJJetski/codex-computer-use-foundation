```bash
  https://github.com/DJJetski/codex-computer-use-foundation/releases/download/v0.1.3/codex-computer-use-foundation-public.tar.gz

  https://github.com/DJJetski/codex-computer-use-foundation/releases/download/v0.1.3/codex-computer-use-foundation-public.tar.gz.sha256
cd /tmp
shasum -a 256 -c codex-computer-use-foundation-public.tar.gz.sha256

cd /tmp/codex-computer-use-foundation-release/codex-computer-use-foundation-public
scripts/install.py --yes --full-ensure
```

## Scope

This release troubleshoots and stabilizes the official native Codex Computer
Use path. It does not bypass OpenAI safety checks, macOS privacy controls,
account protections, or third-party security controls.

The native route stays plugin-only and fallback-free: AppleScript,
Accessibility scripting, screenshots, `cliclick`, Keyboard Maestro, Playwright,
and VPN are not hidden inside the Computer Use MCP path.
