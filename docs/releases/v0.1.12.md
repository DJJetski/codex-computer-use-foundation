# v0.1.12

Chrome readiness and native smoke hardening after v0.1.11.

## What Changed

| Area | Change |
| --- | --- |
| Codex 26.519 validation | Updated native health checks for Codex 26.519.22136 and Computer Use plugin 1.0.799, including the current full MCP tool surface. |
| Native Chrome smoke | Added a separate Chrome target smoke that stays inside native Computer Use and verifies the user's normal Google Chrome app/profile with `get_app_state`, `press_key`, and `set_value`. |
| Chrome Extension readiness | Added `chrome-plugin-status` so the official Codex Chrome Extension route is reported separately from native Computer Use and the in-app Browser plugin. The guard enables and checks the bundled Chrome plugin, but native-host and extension setup still stay in the official Codex Plugins flow. |
| Native smoke cleanup | Treats Calculator close as best-effort cleanup and bases operational health on structured MCP evidence: native app discovery, app-state inspection, element-index clicks, typing, display verification, cleanup keypress completion, and `fallback_used=false`. |
| Public docs | Tightened README, runbook, current-state, and parity wording so release readers can distinguish native Computer Use, native Chrome target proof, Codex Chrome Extension readiness, dialog autopilot, and stale-thread transport state. |

## Why

The current Codex desktop build can expose both native Computer Use and a
separate Chrome Extension path. Those are useful for different browser tasks,
but they should not be collapsed into one health signal. Native Computer Use
health still requires the official MCP tool surface and fallback-free live
evidence. Chrome Extension readiness is a separate setup status that may require
the user to remove and re-add the Chrome plugin in Codex Plugins and confirm the
extension shows Connected.

The native smoke now avoids a false-negative edge where all structured
interaction proof succeeded but the final assistant text did not report the
temporary Calculator window as closed. Cleanup is still attempted, but the
release proof is the fallback-free MCP evidence.
