`codex-computer-use-guard ensure`: structural routing is healthy, the current
native smoke is fresh, Calculator interaction used native MCP calls, and
`fallback_used=false`.

The separate Chrome target smoke previously verified the user's normal Google
Chrome app through native Computer Use. The official Codex Chrome Extension
route remains a separate readiness lane: on this Mac the active Chrome profile
does not currently have the Codex Chrome Extension installed, and the Chrome
native messaging host manifest is absent. That is not repaired by writing a
manifest from this package; the official fix remains removing and re-adding the
Chrome plugin from Codex's plugin/connection setup flow and confirming the
extension shows Connected in Chrome.
