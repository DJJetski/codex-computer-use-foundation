# Security Policy

## Supported Versions

Security fixes target the current `main` branch and the latest published public
release package generated by `scripts/build-public-release.py`.

Older generated tarballs, private maintainer notes outside this repository,
and machine-local runtime state are not supported release surfaces.

## Reporting A Vulnerability

Report vulnerabilities privately. Prefer GitHub private vulnerability reporting
or a private repository security advisory when that feature is enabled for the
repository. A public repository should not be published until private
vulnerability reporting or another maintainer-approved private security contact
is configured. If you are a collaborator and private vulnerability reporting is
not available, use the existing private maintainer channel for this repository.

Do not include secrets in reports. Redact tokens, cookies, OAuth data, local
usernames, full home paths, smoke result JSON, rollback snapshots, and raw
`$HOME/.codex` state unless a maintainer explicitly asks for a sanitized
excerpt.

Useful reports include:

- affected release, commit, or tarball SHA256
- macOS and Codex versions
- exact command or workflow that exposed the issue
- expected and actual behavior
- redacted logs or verifier output
- whether the issue affects installation, verification, runtime repair, or the
  generated public release package

## Security Boundaries

The native Computer Use MCP path must stay fallback-free. AppleScript,
Accessibility scripting, screenshots, `cliclick`, Keyboard Maestro,
Playwright, and VPN must not be hidden inside the Computer Use MCP path.

`codex-dialog-autopilot` is a separate local-dialog operator helper. It is not
native Computer Use health evidence and must not be used to mask native MCP
failures. It does not edit TCC databases, grant macOS permissions, bypass
OpenAI or macOS safety checks, approve privacy, account, cloud, security,
payment, TCC, password, or SecurityAgent dialogs, or count as native Computer
Use success. Strong local-dialog approval requires both an allowlisted helper
process and allowlisted routine-dialog text.

This repository is for troubleshooting and stabilizing the official native
Codex Computer Use route. It is not intended to bypass OpenAI usage policies,
OpenAI safety checks, macOS privacy controls, account protections, or
third-party security controls.
